# پل متاتریدر — این پوشه روی کامپیوتر ویندوزی اجرا می‌شود

متاتریدر ۵ فقط روی ویندوز کار می‌کند. سرور اوبونتو **از راه این پل** به
ترمینال متاتریدرِ روی کامپیوتر تو وصل می‌شود. دو فایل هست:

| فایل | کارش |
|---|---|
| `start-bridge.ps1` | به ترمینال بازِ متاتریدر وصل می‌شود و آن را روی `127.0.0.1:5555` سرو می‌کند. بار اول یک **توکن** چاپ می‌کند. |
| `tunnel.ps1` | یک تونل SSH به سرور باز نگه می‌دارد تا سرور، پل را روی `127.0.0.1:5555` خودش ببیند. |

## اجرا (هر بار که کامپیوتر را روشن می‌کنی)

1. متاتریدر ۵ را باز کن و مطمئن شو پایین پنجره **Connected** است.
2. روی `start-bridge.ps1` راست‌کلیک → **Run with PowerShell**. بار اول
   پایتون و بستهٔ MetaTrader5 را نصب می‌کند (یکی دو دقیقه). بعد می‌نویسد:
   ```
   [bridge] attached to AMarkets account 123456 (DEMO) on AMarkets-Demo
   [bridge] serving. Leave this window open.
   ```
3. یک PowerShell دیگر باز کن، به این پوشه بیا و:
   ```powershell
   .\tunnel.ps1 -Server آی‌پی‌سرور -User ubuntu
   ```
   بار اول رمز سرور را می‌پرسد. **این پنجره را هم باز بگذار.**

هر دو پنجره باید باز بمانند. اگر کامپیوتر خاموش شود، ربات روی سرور معاملهٔ
تازه باز نمی‌کند (و در داشبورد می‌گوید چرا)؛ معامله‌های باز حد ضررشان را
**سمت بروکر** دارند و در امان‌اند.

## توکن

`start-bridge.ps1` بار اول این را چاپ می‌کند:
```
[bridge] SENTINEL_MT5_BRIDGE_TOKEN=xxxxxxxxxxxxxxxxxxxx
```
همان را روی سرور به این دستور می‌دهی (فقط یک بار):
```bash
sudo /opt/sentinel-fx/deploy/scripts/connect-mt5.sh
```
توکن در فایل `bridge.token` کنار همین اسکریپت می‌ماند. به کسی نده.

## بدون پنجرهٔ باز (اختیاری)

اگر می‌خواهی با روشن شدن ویندوز خودکار اجرا شود: Task Scheduler → Create
Task → Trigger «At log on» → Action:
```
powershell.exe -ExecutionPolicy Bypass -File "C:\sentinel\sentinel-fx\deploy\mt5-bridge\start-bridge.ps1"
```
و یک Task دیگر برای `tunnel.ps1` با `-Server ... -User ...`. برای تونل بدون
رمز، کلید SSH بساز (`ssh-keygen`) و کلید عمومی را در
`~/.ssh/authorized_keys` سرور بگذار.

## اگر ویندوز نداری

پل روی هر جایی که ترمینال متاتریدر اجرا شود کار می‌کند — از جمله یک VPS
ویندوزی کوچک، یا Wine روی خود سرور اوبونتو با پایتون ویندوزی (پیشرفته؛
پشتیبانی نشده). پروتکل آن سادهٔ JSON روی TCP است و در
`sentinel/brokers/mt5_bridge.py` مستند شده.
